Away

This long without typing or moving the mouse is time away, and it ends a sitting. A shorter pause between two stretches of work counts as work. ActivityWatch follows it: Save sets its AFK timeout to the same and restarts it.

While Pulsar is paused (Pause at the top, or the Dock icon's menu), nothing counts as work. If it has been paused this long and the tracker sees you working, Pulsar asks whether the pause is still on.

Back after time away (15 minutes or more, under three hours), a small panel near the menu bar offers to log it, for a call or a whiteboard. Ignored, it stays a break. Changes at once, no Save needed.

Fix changes that one line in ActivityWatch's file and keeps a copy of the file next to it, then restarts ActivityWatch. Days already recorded keep their breaks: the new timeout applies to new data only.

Pulsar asks macOS through System Events. The first time, macOS asks whether Pulsar may control System Events (Privacy & Security, Automation): allow it, or nothing can be checked or added.

Claude Code

The Likely column reads your Claude Code sessions on this Mac. Nothing is sent anywhere unless you switch on Claude Code below.

Past days of the Likely column, with session titles and first messages, stay on this Mac this long. The day view and the Report’s parallel work reach that far back. Task picks use their own record and do not change with it.

What Claude does, and with which model

Runs your own Claude Code, on your plan. Haiku is fastest and cheapest, Opus slowest and dearest. Each request to Claude stops at a cost cap that depends on the model. Task picks with Sonnet cost about $0.10 to $0.25 a day.

With the switch on, Claude Code's file tools are kept out of Pulsar's folders; a script can still read them unless Claude Code's sandbox is on.

Works only while “Use Claude Code with Pulsar” is on.

Every Claude Code session on this Mac, not only Pulsar's, will ask you before it changes anything in Productive.
