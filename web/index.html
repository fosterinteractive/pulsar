What Claude does, and with which model

Each runs your own Claude Code, under your Claude plan. Each name is the latest model of that kind: Haiku is the fastest and costs least, Opus is the most careful, slower, and costs most. A run stops at its limit, which grows with the model. With Sonnet, Ask Claude has cost about $0.10 to $0.25 a day; with Haiku, a note costs under half a cent. On the rows Log the day is unsure of, Haiku did as well as Sonnet. Answers last until Pulsar restarts.

Pulsar's folders are kept out: deny rules in Claude Code's settings stop its file tools reading or changing Pulsar's key, sign-in code and settings, and the file commands it recognizes in a shell (cat, head, a redirection); a script that opens the files itself is stopped only with Claude Code's sandbox on. Pulsar does not turn the sandbox on.
