Claude Code

Pulsar reads your Claude Code sessions on this Mac to show which project each stretch of work went to (the Likely column), and learns from what you log which tasks belong to them. Nothing leaves this Mac unless you switch on Claude Code below.

  • Ask Claude in the Likely column: the task for each block of work, with its note.
  • Notes drafted for you in the log dialog, from that session and your commits.
  • Log from a session: say “log the time of this session” in Claude Code. It reads your day from Pulsar and asks you before each write, showing every entry in it.
  • Claude Code asks you before any session changes Productive by itself.

Ask Claude sends, for each block, its time, repository and session titles, what you typed in those sessions with Claude's replies, your commit subjects and a few of your earlier notes, and the tasks you logged to in the last 30 days, to Anthropic through your own Claude Code, which may search Productive (read only). 15 to 60 seconds; one run may use at most $0.25 (Haiku), $0.75 (Sonnet) or $2 (Opus) of your Claude usage, about $0.10 to $0.25 a day with Sonnet. Answers last until Pulsar restarts. A note in the log dialog uses Haiku: a few seconds and under half a cent. Each name is the latest model of that kind in your Claude Code. Log the day asks it too, for the rows Pulsar is unsure of: Haiku did as well as Sonnet there, at a small part of the cost.
